# 마이 사운드 북마크

경구중학교 **코딩으로 보는 세상** 동아리의 2026 대구 메이커페스타 체험 웹앱입니다.

## 주요 기능

- 사진 촬영 또는 사진 파일 불러오기
- 7~14개 음, 최대 5초의 음악 연주 기록
- 개인 음악 데이터 QR 생성
- Canon QX20·XS-20L용 1:1 정사각 결과 이미지 저장·인쇄
- 사진 오른쪽 아래에 둥근 모서리의 음악 QR 하나만 배치한 간결한 인화 레이아웃
- 작품 QR 카메라 스캔, 간단 악보 표시, Web Audio 재생
- 사진과 음악을 서버에 저장하지 않는 클라이언트 전용 처리

## 로컬 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm test
npm run build
```

빌드 결과는 GitHub Pages 게시용 `docs/` 폴더에 생성됩니다.

## 개인정보 처리 원칙

- 촬영한 얼굴 사진은 브라우저 메모리에서만 처리합니다.
- 사진은 QR에 포함하거나 서버로 전송하지 않습니다.
- 작품 QR에는 음높이, 연주 시점, 음 길이, 악기 번호만 저장합니다.
- QR 스캔 카메라 영상은 브라우저 안에서만 분석합니다.
